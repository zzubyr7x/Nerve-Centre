The dashboard constitution — Save7 OS.

#35 settled that the Dashboard is per seat. That makes a frame mandatory: it is the only thing standing between one surface rendered twelve ways and twelve pages that drift. Four frames below, each a different answer to what every dashboard carries, in what order, and what a dashboard is allowed to be. Flip with the bar at the bottom (or ← →). Switch seats to see whether a frame survives contact with all of them.

Amber marks a question this prototype refuses to answer

  1. Announcements — who writes one, who sees it, how long it lives. Nothing in the map has claimed this surface, and #35 just put it on the most-seen screen in the product.
  2. MOU status and quick-links into hubs — both proposed, neither settled. The case against: a dashboard that becomes a noticeboard stops being read. Frame A shows them, frame B refuses them.
  3. Work with no hub — #30 has not placed Projects in a hub yet, so assigned project work has no section in frame C. That is a finding about frame C, not a gap in the data.
  4. Per-person preferences — card order, collapsed sections. #35 Q7 asks whether this map decides that at all.
  5. A trio's shared duty — see the note under "already settled": a draft answer exists but is not yet on main.
Already settled and rendered as given: everyone has one and it is the landing page; it is per seat; it carries action points (overdue in red), assigned work, who you are, what you must act on as a seat-holder, and Exco announcements; action points are ticked done from here by their owner; authority is not obligation — a duty sits with the lowest level that can act on it; one merged queue badged by the hat it arrives through; the card set is not written up front; Super Admin generates nothing.

In flight, not settled: an uncommitted CONTEXT.md draft in the working tree mints Duty for the thing owed, and splits it into raised (stored, ticked) and standing (computed from a state, aggregates, nothing to tick — which would dissolve the trio question, since any one of the three acting clears the state for all three). This prototype uses that vocabulary and marks rows accordingly, because it is the only candidate on the table — but it is not on main and #55 does not settle it.
