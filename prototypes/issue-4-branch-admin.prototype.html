Branch management (Admin UI).

Question this demo answers: does a standalone admin screen — separate from the six role-gated content hubs, and reachable by both Admin and National Exco — let them list, add, edit, delete, and mark a branch active/inactive, with duplicate names rejected? Active/Inactive here is a health-and-activity status (does this branch currently have momentum?), not a stand-in for whether the branch still exists — that's what Delete is for. Free-play the table below (toggle who's logged in via the topbar), or click through a guided scenario. Everything resets when you restart a scenario.

Per issue #12's role model: Branch is an admin-managed, open-ended list (same pattern as Department, issue #14 — not built here, but this screen's shape is meant to generalize to it).
