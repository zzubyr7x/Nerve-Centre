Branch management (Admin UI)

Question this demo answers: does a standalone Admin screen — separate from the six role-gated content hubs — let Admin list, add, edit, and deactivate/reactivate branches, with no way to permanently delete one, and with duplicate names rejected? Free-play the table below, or click through a guided scenario. Everything resets when you restart a scenario.

Per issue #12's role model: Branch is an admin-managed, open-ended list (same pattern as Department, issue #14 — not built here, but this screen's shape is meant to generalize to it).
